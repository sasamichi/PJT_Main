# データ精度管理表（品質・基準件数ベンチマーク）

本ドキュメントは、世界各国の公的統計・公式発表に基づく「正解件数（基準値）」を記録し、収集スクリプトの実行結果と突合することで、データの**抜け落ち**や**廃止データの混入・重複**を客観的に検知・防止するための管理資料です。

---

## 1. 精度管理ルール

1. **公的基準値の事前設定**: 新しい国・分野の収集を行う前に、必ず各国の統計局・国土交通省等の公式発表から基準件数を調査して本表に登録する。
2. **実行後の自動突合**: データ収集スクリプトの実行後、本表の公的基準値とマスタCSVの行数を比較する。
3. **判定基準**:
   - **合格（一致）**: 基準件数と完全に一致、または既知の理由（例: 北方領土の村を含む等）で乖離が説明可能な場合。
   - **要調査（不足）**: 基準件数より少なく、重要拠点や路線の抜け落ち（インスタンス指定ミス等）の疑いがある場合。
   - **要調査（過剰）**: 基準件数より多く、廃止自治体・廃止線・計画線の混入やID重複の疑いがある場合。
4. **地域別進捗管理の範囲に関する決定事項**:
   - 進捗管理台帳における「地域」の設定範囲は国によって行政階層が大きく異なるため、全世界の上位行政区画（都道府県・州・県等）の収集完了後に改めて検討する。
   - したがって、**現状の進捗管理は「国レベル」に限定して管理・運用する**（`data/master/country_progress.csv`）。
