## 3. ドキュメント更新・国別収集運用ルール（人間・LLM共通）

1. **参照の順序**:
   - スレッド開始時は、まずルートの [プロジェクト仕様書.md](../プロジェクト仕様書.md) と本ファイル（`04_進捗と引継ぎボード.md`）を確認する。
   - データ収集・加工時は `01` と `02` を参照し、画面・ツール改修時は `02` と `03` を参照する。
2. **国別事前調査ゲートの厳守（再発防止ルール）**:
   - 新しい国の収集に入る際は、**必ず最初に [`.agents/skills/country-pre-research/SKILL.md`](../.agents/skills/country-pre-research/SKILL.md) を最終行（189行目）まで全文読了**し、`行政・気象編` と `交通編` の2分冊を作成・検算して [`docs/精度基準マスタ.csv`](精度基準マスタ.csv) を更新し、ユーザーの承認を得てからデータ収集スクリプトを実行すること（事前調査のスキップやスキル定義書の途中読み止めは厳禁）。
3. **更新の原則（散逸防止）**:
   - 新たな仕様変更やカラム追加が発生した場合は、新しいメモファイルを乱立させず、必ず **`01`・`02`・`03` の該当箇所を直接書き換えて最新状態を維持（上書き更新）** する。
   - 一時的な検証レポートや抜き取りチェック結果を作成した場合は、確認完了後に `docs/archive/` フォルダへ移動して整理する。
4. **`docs/archive/` の扱い**:
   - `docs/archive/` 内のファイルは過去の検討経緯の保存用であり、現行仕様としては参照しない。
