### 作業・品質管理の5大基本ルール ＆ スキーマv3凍結
- **① スキーマv3凍結**: 全14テーブルの列定義・ID体系（[docs/02](02_データベース設計書_スキーマ.md)）はステップ2完了まで変更しない。
- **② セッション完了**: 時間・柔軟区切りルール（無理に完結させず、キリの良いところでバックアップ＆引継ぎ更新）。
- **③ バックアップ**: マスター更新時は `data/backup/{filename}_{timestamp}.bak` へ自動退避、区切りでGitコミット。
- **④ 二重品質監査ゲート**: ステージング（`data/staging/`）で路線単位の `tools/gate_audit.py`（Gate 1〜4）を通過させ、マスター反映後に `scripts/validators/audit_integrity.py`（Gate 1〜5：回帰防止含む）で **ALL PASS** を取得して完了とする（件数・充足数増加時は `--update-baseline` で基準更新）。
- **⑤ 本番直プッシュ禁止 ＆ 3段階承認ゲート**: ローカルテスト環境での目視確認 ➔ ユーザーへの確認提示・承認 ➔ GitHub本番反映を絶対遵守。

## 2. 次期スレッドへの引継ぎ（コピー用プロンプト）

次期スレッド開始時は、以下の枠内プロンプトをそのままコピー＆ペーストして指示を開始してください。

```markdown
前スレッドでプロジェクト全体の検証と改善作業を実施し、全14テーブルのスキーマv3凍結、edges.csvの全220件主キー修復、nodes.csv外部キー修復、札樽自動車道（JP-RT-001422）・後志自動車道（JP-RT-001423）の正規路線登録、および回帰防止付きの独立品質監査エンジン（scripts/validators/audit_integrity.py：Gate 1〜5 ALL PASS）の配備が完了しています。

本スレッドでは、北海道回廊パイロット（ステップ2）の次期対象路線である以下の高速道路2路線のデータ収集・検査・マスター昇格に着手してください：
1. 札樽自動車道（E5A, 小樽IC 〜 札幌JCT, 38.3km, 対象ID: PLT-HW-02, 路線ID: JP-RT-001422）
2. 後志自動車道（E5A, 余市IC 〜 小樽JCT, 23.3km, 対象ID: PLT-HW-03, 路線ID: JP-RT-001423）

作業にあたっては、以下の基本方針を厳格に遵守してください：
・結論ファースト、挨拶・社交辞令不要、日本語対応、問題点は隠さず報告。
・スキーマv3（全14テーブルの列定義）を厳守し、勝手に列を変更・追加しない。
・道央道で確立した「オープンデータ3段階補完パイプライン（Wikipedia路線表 ➔ Wikidata/MediaWiki API ➔ 自治体コード空間特定）」に従う。
・データはまず data/staging/JP/routes/（PLT-HW-02_nodes.csv / PLT-HW-02_edges.csv 等）に作成し、tools/gate_audit.py による Gate 1〜4 決定論的論理検査を実行する。
・既存マスター（nodes.csv の既存IC/JCTノード、特に札幌JCTや小樽JCT等の結節点）との名寄せ・正規ID引き継ぎ、新規施設の正規連番採番（JP-ND-*）、新規エッジの正規連番採番（JP-ED-000221〜）を徹底する。
・マスター昇格後、必ず python scripts/validators/audit_integrity.py --update-baseline を実行し、全5ゲート ALL PASS の出力結果をそのまま貼って報告し、GitHub本番反映前にユーザーの確認・承認を得る。
```
