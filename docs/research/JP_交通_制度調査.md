## 1. 道路法体系と道路分類

### 1.1 道路法上の分類と公的路線数・実延長

日本の道路網は道路法第3条に基づき4分類され、管理主体および整備基準が明確に区分されている。

| 道路種別 | 法的根拠 | 主な管理者 | 路線数 | 実延長（km） | 本基盤の収集方針 |
| :--- | :--- | :--- | :---: | :---: | :---: |
| **高速自動車国道** | 道路法第3条第1号、高速自動車国道法 | 国土交通大臣（NEXCO東日本・中日本・西日本等へ管理委託） | 約100路線 | 約9,000 km | **全線・全IC/JCT網羅収集** |
| **一般国道（指定区間）** | 道路法第3条第2号、道路法施行令 | 国土交通省（地方整備局・開発局・沖縄総合事務局：直轄国道） | - | 約24,000 km | **全459路線・主要点網羅収集** |
| **一般国道（指定区間外）** | 道路法第3条第2号（補助国道） | 都道府県および政令指定都市 | - | 約31,000 km | **全459路線・主要点網羅収集** |
| *(計)* **一般国道合計** | - | - | **459路線** | **約55,000 km** | **1号〜507号（欠番48路線を除く実路線全線）** |
| **都道府県道（主要地方道）** | 道路法第56条（大臣指定） | 都道府県および政令指定都市 | 約4,000路線 | 約60,000 km | **主要交差点・峠・旧道を順次収集** |
| **都道府県道（一般県道）** | 道路法第3条第3号 | 都道府県および政令指定都市 | 約1万路線 | 約70,000 km | 初期自動取得除外（探索時追加） |
| **市町村道** | 道路法第3条第4号 | 各市町村・特別区 | 約100万路線 | 約100万 km | 初期自動取得除外（探索時追加） |

### 1.2 高速道路・有料道路ナンバリング体系
- **高速道路ナンバリング**: 2文字英数記号（`E1` 東名・名神、`E4` 東北道、`C3` 東京外環道等）。
- **都市高速道路**: 首都高速道路、阪神高速道路、名古屋高速道路、福岡高速道路、北九州高速道路、広島高速道路。
- **本州四国連絡道路**: 神戸淡路鳴門自動車道（`E28`）、瀬戸中央自動車道（`E30`）、西瀬戸自動車道（`E76`）。

### 1.3 道路構造物（トンネル・橋梁・峠）の基準
- **トンネル・橋梁**: 直轄国道・高速道路上の長大トンネル（1,000m以上）および主要橋梁をノード種別 `トンネル`, `橋梁` として定義。区間エッジの `中間構造物_node_ids` に起点から順次紐付け。
- **峠（とうげ）**: 国道・主要地方道・旧街道の分水嶺・峠をノード種別 `峠` として定義。自治体境にある峠は `municipality_id` に複数自治体を格納。

### 2.2 現行鉄道駅数・路線数の公的基準値
- **全国現行鉄道駅数**: **約9,300 〜 9,500駅**（旅客駅・停留場。国土交通省「鉄道統計年報」基準）
- **鉄軌道路線数**: **約550 〜 600路線**（JR各線、私鉄本線・支線、地下鉄各線）
- **キロ程基準**: 国土交通省『鉄道要覧』および各社公式営業キロ程（十進数・小数第1位〜第3位km）。

### 2.3 駅ナンバリング体系
- 首都圏・関西圏・JR・地下鉄各社で導入されている公式記号（JR東日本: `JY17`, `JC01`、東京メトロ: `M17`, `G09` 等）。
- 複数路線乗り入れ駅はノードを1つとし、`edges.csv` の `from_路線内番号`・`to_路線内番号` に格納。

## 3. バス事業体系

### 3.1 道路運送法上の事業種別と初期収集範囲
- **一般乗合旅客自動車運送事業**:
  - **高速バス（都市間長距離バス）**: 路線・主要停留所（バスターミナル等）を収集対象とする。
  - **空港連絡バス**: 主要駅・ホテル等と旅客空港を結ぶ系統を収集対象とする。
  - **一般市内路線バス・コミュニティバス**: 初期自動収集から**除外**（データ量膨大・改編頻度高のため）。
- **一般貸切・特定旅客自動車運送事業**: 初期収集から**除外**。
