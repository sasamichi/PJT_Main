# オーストリア (AT) 制度・変遷 事前調査シート

## 1. 対象国基本情報
- **国名**: オーストリア共和国 (Republic of Austria / Republik Österreich)
- **ISO 3166-1コード**: Alpha-2: `AT`, Alpha-3: `AUT`, 数値: `040`
- **公用語**: ドイツ語（地域的にクロアチア語、スロベニア語、ハンガリー語も公認）
- **国家体制**: 連邦共和制（9連邦州）

## 2. 行政区画・地域制度の変遷と現行構造
### 2.1 行政階層
| 階層レベル | 現地公用語名称 | 日本語相当 | 公式現行件数 | 主な役割・自治権 |
| :---: | :--- | :--- | :---: | :--- |
| **第1階層** | **Bundesland** | **連邦州** | **9州** | 自治州（独自の州憲法・州議会・州政府を保有） |
| **第2階層** | **Politischer Bezirk** | **郡** | **79郡** | 州の出先行政機関（自治権なし） |

| **第3階層** | **Gemeinde** | **基礎自治体** | **2,093自治体** | 基礎地方公共団体（市、市場町、一般町村） |

### 2.2 近年の大規模変遷（廃止データ混入防止の境界線）
- **2015年 シュタイアーマルク州自治体構造改革 (Gemeindestrukturreform Steiermark)**:
  - 州内の自治体数が542から287へ激減。州内の旧郡（Bezirk Judenburg, Knittelfeld等）も統合された。
  - **重要**: Wikidata上で旧自治体にも `P964`（Gemeindecode）が残っているケースが多く、現役フィルター（`FILTER NOT EXISTS { ?item wdt:P576 ?end . }` に加え、`wdt:P31` に「旧自治体」が含まれていないか）を厳格に適用しないと旧自治体が約190件混入する。

## 3. 公式コード体系
### 3.1 国内公式コード
- **Gemeindecode（自治体コード / 5桁）**:
  - オーストリア統計局（Statistik Austria）が管理。
  - 1桁目: 連邦州番号（1: ブルゲンラント 〜 9: ウィーン）
  - 2〜3桁目: 郡番号（01〜99）
  - 4〜5桁目: 自治体連番（01〜99）
  - （例: ウィーン市 `90001`、シュヴェヒャート市 `32419`）

### 3.2 国際・地域標準コード
- **ISO 3166-2:AT**: `AT-1`（ブルゲンラント）〜`AT-9`（ウィーン）。
- **NUTSコード（EU地域統計分類）**:
  - `NUTS 1`: `AT1`（東オーストリア: ウィーン・下墺・ブルゲンラント）, `AT2`（南墺）, `AT3`（西墺）
  - `NUTS 2`: 各連邦州（`AT11` ブルゲンラント 〜 `AT13` ウィーン）
  - `NUTS 3`: 郡・小地域（例: `AT130` ウィーン）
- **UN/LOCODE**: `ATVIE`（ウィーン）、`ATSZG`（ザルツブルク）、`ATINN`（インスブルック）等。

### 4.2 鉄軌道・交通拠点
- **主要鉄道**: オーストリア連邦鉄道 (ÖBB)、WESTbahn（民間高速鉄道）、各州公社（NÖVOG等）。
- **都市交通**: ウィーン地下鉄（U-Bahn: U1〜U6、全109駅）、各都市トラム（ウィーン、グラーツ、リンツ、インスブルック）。
- **主要駅のWikidataクラス構造**:
  - 「ウィーン中央駅 (Q698199)」や「ザルツブルク中央駅 (Q800926)」は、Wikidata上で `中央駅 (Q55491 / Hauptbahnhof)` に分類されている。
  - **解決策**: SPARQLで `?station wdt:P31/wdt:P279* wd:Q55488` とサブクラスを含める検索を行うこと。
- **駅コード規格**: **UIC駅コード**（オーストリア国番号: `81`）。例: ウィーン中央駅 `8100187`。
