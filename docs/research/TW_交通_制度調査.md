### 1.2 付番ルール・管理者・OSMタグ対照表

- **主要幹線道路の路線番号付番規則と例外ルール**:
  - 南北縦貫・縦走路線に奇数、東西横断・連絡路線に偶数を割り当て、北から南へ、西から東へ向かって昇順に増加。
  - 國道: 1〜10の番号帯を使用。奇数（國道1号・3号・5号）は南北縦貫幹線としてETC距離制課金。偶数（國道2号・4号・6号・8号・10号）は東西連絡・空港アクセス線で原則無料。
  - 省道: 一般省道（1〜39番、青盾標識）は島内縦貫・周回主要幹線。省道快速公路（61〜88番、赤盾標識）は高規格幹線。
  - 支線表記: 十干（甲・乙・丙・丁・戊・己・庚）を付加（例: 台1甲線、台9乙線）。英語表記・GIS識別子ではアルファベット（A, B, C, D, E, F, G）へ1対1変換。
  - 市道・縣道: 3桁番号（101〜205号）を通し番号で使用。直轄市と県の境を跨ぐ路線は番号不変で法的種別（市道/縣道）のみ切り替わる。
  - 區道・鄉道: 自治体の漢字1文字略称を冠して付番（例: `北28線`、`竹21線`）。県境を跨ぐ際に路線番号自体が別番号へ変化するため、境界ノードでの異番号エッジ結合が必要。
- **OSMにおける道路タグ対照関係**:
  - 國道（本線・支線）: `highway=motorway`, `ref=1`, `3`, `3甲`, `5` 等, ネットワーク: `network=TW:freeway`, 接続路: `motorway_link`
  - 省道快速公路（台61〜88線）: `highway=trunk`, `ref=61`, `74`, `88` 等, `network=TW:expressway`, `motorroad=yes`
  - 省道（一般省道）: `highway=primary`（蘇花改・南廻改等バイパス区間は `trunk`）, `ref=1`, `9` 等, `network=TW:provincial`
  - 市道・縣道: `highway=secondary`, `ref=101`, `106乙` 等, `network=TW:city` / `TW:county`
  - 區道・鄉道: `highway=tertiary`, `ref=北1`, `竹21` 等, `network=TW:district` / `TW:township`
  - 市區道路: 都市幹線街路（`primary`〜`residential`）。「路→段→巷→弄」の階層構造。
- **国直轄区間と地方自治体・公社管理区間の管理分担**:
  - 國道: 交通部高速公路局（高公局）が国直轄管理（公社民営化ではなく国営行政機関直轄）。
  - 省道: 交通部公路局が国直轄管理。
  - 市道・區道: 各直轄市政府が管理。縣道・鄉道: 各縣（市）政府が管理。都市計画区域内の重用区間は路線指定を公路局/県が、歩道・路面維持を自治体工務局が分担。

## 7. 路線の繋がり（順序）の公式基準 ＆ 駅順データ調達

- **起点〜終点までの順序を決定する公式基準**:
  - 道路網: 『公路法』に基づく「公路路線里程表」の法定起点（`0K+000`）〜法定終点。南北路線は北→南、東西路線は西→東へ向かって累積キロ程が増加（順樁方向）。IC・服務區の順序はこの昇順で一意に決定。
  - 台湾鉄路（TRA）: 法令指定の起点駅（縦貫線北段＝基隆 `0.0km`、海岸線・台中線＝竹南 `0.0km`、縦貫線南段＝彰化 `0.0km`、屏東線＝高雄 `0.0km`、宜蘭線＝八堵 `0.0km`、北廻線＝蘇澳新 `0.0km`、台東線＝花蓮 `0.0km`、南廻線＝枋寮 `0.0km`）からの営業キロ昇順および4桁公式駅コード（`StationID`）。時計回り・北→南方向が「順行」、逆が「逆行」。
  - 台湾高速鉄道（THSR）: 南港（01）から左営（12）への駅番号および累積キロ程昇順。
  - 都市捷運・LRT: 南/西端を01とする駅ナンバリング（桃園捷運は台北車站A1から南西方向）およびTDXの `StopSequence` 昇順。
- **公式路線網台帳の入手先**:
  - 交通部TDX `StationOfRoute` / `StopOfRoute` API（`StopSequence`, `CumulativeDistance` 完備）: `https://tdx.transportdata.tw/`
  - 交通部公路局「公路路線里程表」およびGISシェープファイル: `https://www.thb.gov.tw/cp.aspx?n=430`
  - 交通部鐵道局「鐵道統計年報」および台鉄公司「各站營業里程表」: `https://www.rb.gov.tw/` / `https://www.railway.gov.tw/`
- **駅順エッジ取得可能性（主系: TDX API）**:
  - **主系**: 交通部TDXの軌道API（`/v2/Rail/TRA/StationOfRoute`, `/v2/Rail/THSR/StationOfRoute`, `/v2/Rail/Metro/StationOfRoute/{Operator}`）および公式GTFS（`stop_times.txt`）から、系統別駅順（`StopSequence = 1, 2, 3...`）を**欠損なく100%自動抽出可能**。分岐系統（中和新蘆線の蘆洲/廻龍支線、淡海軽軌の緑山/藍海線等）も完全対応。
  - **補完**: OpenStreetMap路線リレーション（PTv2準拠）から軌道ウェイ空間ポリラインを抽出。Wikidata（`P197`）は公式駅コード（`P296`/`P11622`）を介したQID・多言語ラベル結合に活用。
