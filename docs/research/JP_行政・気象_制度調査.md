### 2.2 国勢調査・統計調査区の体系
- **基本単位区（Basic Unit Block）**: 街区や自然境界によって区切られた最小調査単位（全国約100万単位区）。
- **町丁・字等（Cho/Aza）**: 住民基本台帳および住所表記に基づく区域（約20万地区）。
- **地域メッシュ（JIS X 0410）**:
  - 第1次地域メッシュ: 緯度40分、経度1度（約80km四方）
  - 第2次地域メッシュ: 緯度5分、経度7分30秒（約10km四方）
  - 第3次地域メッシュ（基準地域メッシュ）: 緯度30秒、経度45秒（約1km四方）
  - 1/2地域メッシュ（500mメッシュ）、1/4地域メッシュ（250mメッシュ）

### 2.3 「政庁所在地（役所・庁舎の点座標）」の公式定義とデータ有無
- **公式定義**: 都庁・道庁・府庁・県庁、および各市役所・区役所・町役場・村役場（本庁舎）の建物位置座標。
- **データ入手元**:
  - 国土交通省 国土数値情報「市区町村役場等及び公的集会施設データ（P34）」
  - 国土地理院「電子国土基本図（地名情報）」
  - 都道府県および基礎自治体全件の緯度・経度は十進数小数第6位精度で取得可能。

### 2.4 過去の変遷・制度改革の歴史
- **明治の大合併（1889年市制・町村制施行）**: 全国約71,000町村が15,859市町村へ統合。
- **昭和の大合併（1953〜1961年町村合併促進法等）**: 市町村数が9,868から3,472へ激減。
- **平成の大合併（1999〜2010年合併特例法）**: 3,232市町村が1,700自治体規模へ半減。
- **直近の大規模再編（2024年1月1日 浜松市行政区再編）**: 7区（中区・東区・西区・南区・北区・浜北区・天竜区）が3区（中央区・浜名区・天竜区）へ統合再編。行政区が175区から171区へ減少。

### 2.5 今後数年内に予定されている大規模な制度変更・再編
- 全国規模の合併強制法制、道州制の導入、都構想等の広域自治体改編は、直近数年内に予定されているものはない。
- 自治体単位の個別市制施行（単独昇格）の検討はあるが、コード体系全体への影響は軽微。

## 3. 公式コード体系

### 3.1 国内公式コード（自治体コード）
- **規格名**: **全国地方公共団体コード（JIS X 0401 / JIS X 0402）**
- **コード体系（6桁）**:
  - 上2桁: 都道府県コード（`01` 北海道 〜 `47` 沖縄県）
  - 次3桁: 市区町村番号（`100`〜 政令指定都市・行政区、`200`〜 市、`300`〜 町村）
  - 末尾1桁: モジュラス11ウェイトによるチェックディジット
- **最新版コードリスト入手先**:
  - 総務省「全国地方公共団体コード」公式ダウンロード
  - URL: `https://www.soumu.go.jp/denshijiti/code.html`
- **過去分・変遷履歴コードリスト入手先**:
  - e-Stat（政府統計の総合窓口）「市区町村名・コード」「廃置分合等情報」（1970年以降の全変遷）
  - URL: `https://www.e-stat.go.jp/`

### 3.2 国際・地域標準コード
- **ISO 3166-2:JP**: `JP-01`（北海道）〜 `JP-47`（沖縄県）。

## 4. 気象機関・予報区・観測網

### 4.1 国家気象機関と予報区・警報区体系
- **国家気象機関名**: 気象庁（Japan Meteorological Agency / JMA）
- **陸上気象予報区の階層構造**:
  1. **地方予報区（全11区分）**: 北海道、東北、関東甲信、北陸、東海、近畿、中国、四国、九州北部、九州南部・奄美、沖縄
  2. **府県予報区（全54区分）**: 都府県単位（北海道6区分、奄美1区分を含む）
  3. **一次細分区域（全142区分）**: 気象特性に応じた府県内の細分（例: 石狩地方、空知地方、後志地方、東京地方、伊豆諸島北部等）
  4. **二次細分区域（約1,700区分）**: 気象警報・注意報の発令単位。市区町村単位（東京23区・政令指定都市は各行政区単位）
- **海上予報区・沿岸警報区体系**:
  - **全般海上予報区**: 日本近海外洋（オホーツク海南部、東シナ海等）
  - **地方海上予報区**: 管区ごとの外洋海域
  - **沿岸海域警報区（全74海域）**: 暴風・波浪・高潮警報を発令する沿岸・内湾水域（東京湾、伊勢湾、瀬戸内海等）

### 4.2 地上気象観測網と観測所地点リスト入手先
- **観測網名称**: アメダス（AMeDAS / Automated Meteorological Data Acquisition System）
- **観測網ネットワーク規模**:
  - 気象官署・特別地域気象観測所: 約155地点
  - アメダス総地点数: **約1,300地点**
    - 4要素観測点（降水量・風向風速・気温・日照時間）: 約840地点
    - 降水観測点（降水量のみ）: 約460地点
    - 積雪観測点（豪雪地帯併設）: 約320地点
- **地点マスターデータ入手先**:
  - 気象庁公式「気象観測所一覧（アメダス）」
  - URL: `https://www.data.jma.go.jp/obd/stats/data/mdrr/chiten/sindex.html`
  - 格納項目: 観測所番号（5桁）、観測所名、所在地（都道府県・市区町村）、緯度・経度、標高（m）
