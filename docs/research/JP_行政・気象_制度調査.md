### 2.2 国勢調査・統計調査区の体系
- **国勢調査調査区（Enumeration District）**: 総務省統計局が5年ごとの国勢調査で設定する調査員1人あたりの担当区域（1調査区あたり概ね50世帯、全国**約75万調査区**）。
- **基本単位区（Basic Unit Block）**: 道路・鉄道・河川等の恒久的な地形地物で囲まれた最小の街区単位（1990年国勢調査より導入、全国**約190万単位区**）。9桁の基本単位区コードで管理。
- **町丁・字等（小地域 / Cho-Aza）**: 市区町村の下位にある住居表示の「〇〇町〇丁目」や地番区域の「大字・字」単位（e-Stat小地域境界データとして全国**約21.8万ポリゴン**が公開）。
- **人口集中地区（DID: Densely Inhabited District）**: 国勢調査基本単位区を基礎とし、人口密度4,000人/km²以上の隣接単位区が市区町村内で人口5,000人以上となる都市的地域。
- **地域メッシュ統計（標準地域メッシュ / JIS X 0410）**: 経緯度に基づく全国統一の格子状統計区画。
  - **第1次地域メッシュ（4桁）**: 緯度40分×経度1度（約80km四方、20万分の1地勢図1図葉相当）。
  - **第2次地域メッシュ（6桁）**: 第1次を縦横8等分（緯度5分×経度7分30秒、約10km四方、2万5千分の1地形図1図葉相当）。
  - **第3次地域メッシュ（基準地域メッシュ・8桁）**: 第2次を縦横10等分（緯度30秒×経度45秒、**約1km四方**）。
  - **分割地域メッシュ**: 2分の1地域メッシュ（500m四方・9桁）、4分の1地域メッシュ（250m四方・10桁）、8分の1地域メッシュ（125m四方・11桁）。

### 2.3 「政庁所在地（役所・庁舎の点座標）」の公式定義とデータ有無
- **公式定義とデータの有無**: 各都道府県庁および各市区町村役場（市役所・区役所・町役場・村役場の本庁舎）の**正確な建物位置座標（Point）**が公的オープンデータとして提供されている（行政領域の幾何学的重心Centroidではない）。
- **公的入手方法**:
  1. **国土交通省 国土数値情報「市区町村役場等及び公的集会施設データ（P34）」**: 全国の市区町村役場（本庁舎：`P34_002 == 1`）、支所・出張所（`P34_002 == 2`）の点座標（世界測地系JGD2011）、名称、所在地住所、行政区域コード（5桁）をShapefile / GeoJSON形式で収録。
  2. **国土地理院「電子国土基本図（地名情報・住居表示住所）」**: 都道府県庁・市区町村役場の建物代表点座標。
  3. **庁舎移転への対応**: 市役所本庁舎が新築移転した場合（例：近年の長崎市役所、青森市役所、徳島県鳴門市役所等の移転）、`nodes.csv` / `municipalities.csv` の改称・移転ルールに基づき座標・履歴を更新可能。

### 2.4 過去の変遷・制度改革の歴史
- **1871年（明治4年）廃藩置県・府県統合**: 約300藩を廃止し、1888年（明治21年）の香川県分立により現行の**47都道府県体制**が確立（1943年東京都制施行、1947年地方自治法施行）。
- **1889年（明治22年）明治の大合併（市制・町村制施行）**: 江戸時代以来の自然村（約71,314町村）を統合し、39市・15,820町村（計15,859市町村）へ再編。
- **1953年〜1961年（昭和28年〜36年）昭和の大合併**: 町村合併促進法および新市町村建設促進法に基づき、9,868市町村（1953年10月）から3,472市町村（1961年6月）へ約3分の1に統合。
- **1999年〜2010年（平成11年〜22年）平成の大合併**: 旧合併特例法および合併新法に基づき、3,232市町村（1999年3月）から1,727市町村（2010年3月）へほぼ半減。
- **直近の自治体・行政区再編（廃止データ混入防止の境界線）**:
  - **2018年10月1日**: 福岡県筑紫郡那珂川町が単独市制施行し「那珂川市」へ移行（これ以降、基礎自治体の新設合併・編入合併・市制施行は発生しておらず、基礎自治体数は **1,741（北方領土含め1,747）** で固定）。
  - **2024年1月1日（浜松市行政区再編）**: 静岡県浜松市の7行政区（中区・東区・西区・南区・北区・浜北区・天竜区、コード`22131`〜`22137`）が廃止され、3行政区（中央区`22138`・浜名区`22139`・天竜区`22140`）へ再編。これにより全国の政令指定都市行政区数は175区から **171区** となった（旧7区および1980年廃止の神戸市葺合区・生田区等を現行データに混入させないこと）。

### 2.5 今後数年内に予定されている大規模な制度変更・再編
- **向こう数年内に予定されている変更**:
  - 国主導の強制的な市町村合併法案や道州制導入の具体的な立法予定はない。
  - 政令指定都市における特別自治市構想や行政区再編の議論（静岡市、堺市、新潟市等での検討事例）はあるが、公布・施行日が確定した再編案件は現時点で存在しない。
  - 人口5万人要件を満たした一部町（例：沖縄県中頭郡読谷村・北谷町、福岡県糟屋郡宇美町・志免町、愛知県海部郡蟹江町等）での単独市制施行の検討は継続的に存在するが、施行時は個別レコードの移行（`historical_transitions.csv` への登録）で対応可能。

## 3. 公式コード体系

### 3.1 国内公式コード（自治体コード・統計区コード）
- **規格名称**: **全国地方公共団体コード（JIS X 0401: 都道府県コード / JIS X 0402: 市区町村コード）**
- **桁数と構造（5桁本体＋1桁チェックディジット＝計6桁）**:
  - **第1〜2桁（JIS X 0401）**: 都道府県コード（`01` 北海道 〜 `47` 沖縄県。北東から南西へ配列）。
  - **第3〜5桁（JIS X 0402）**: 市区町村コード。
    - `000`: 都道府県そのものを表す（例：北海道庁 `010006`）。
    - `100`〜`199`: 政令指定都市および東京都特別区。政令指定都市の市全体は下2桁`00`（例：札幌市 `011002`、大阪市 `271004`）、その内部の行政区は`101`〜（例：札幌市中央区 `011011`、浜松市中央区 `221384`）。東京都特別区は `131016`（千代田区）〜 `131237`（江戸川区）。
    - `201`〜`299`: 一般の市（中核市・施行時特例市を含む。市制施行順に採番、例：函館市 `012025`）。
    - `301`〜`799`: 町村および郡。原則として郡ごとに20番単位のブロック（`300`番台〜）が割り当てられ、郡内の町村に`301`, `302`...が振られる（北海道のみ振興局単位等の特例配列あり）。
  - **第6桁（検査数字 / チェックディジット）**: 第1〜5桁の各数字に左からウェイト `6, 5, 4, 3, 2` を掛けて合計し、`11` で割った余りを `11` から引いた値（差が10の場合は`1`、11の場合は`0`）を付与する**モジュラス11（ウェイト2〜6）方式**。※国土数値情報や気象庁等のGISデータではチェックディジットを除いた**上5桁**が用いられることが多い。
- **最新版コードリストの入手先**:
  - **総務省「全国地方公共団体コード」公式ページ**: 現行の都道府県・市区町村コード一覧（Excel / PDF、6桁コード・漢字名・半角カナ名収録）。
    - URL: `https://www.soumu.go.jp/denshijiti/code.html`
  - **地方公共団体情報システム機構（J-LIS）**: 地方公共団体コード住所一覧（政令指定都市の行政区コードを含む最新版）。
    - URL: `https://www.j-lis.go.jp/spd/code-address/jititai-code.html`
- **過去分・変遷履歴コードリストの入手先**:
  - **政府統計の総合窓口（e-Stat）「統計に用いる標準地域コード」**: 1970年（昭和45年）4月1日以降の全ての市町村合併・廃止・新設・名称変更・コード改定履歴（廃置分合等情報）をCSV形式で提供。
    - URL: `https://www.e-stat.go.jp/municipalities/cities/areacode`

### 3.2 国際・地域標準コード
- **ISO 3166-2コード**: `JP-01`（北海道）〜 `JP-47`（沖縄県）。JIS X 0401の都道府県番号（2桁）と完全に一致する。
- **地域標準コード**: 日本はEU非加盟のためNUTS / LAUコードは存在しない（国内では総務省標準地域コード・JISコードが同等の役割を果たす）。

## 4. 気象機関・予報区・観測網

### 4.1 国家気象機関と予報区・警報区体系（陸上および海上）
- **国家気象機関名**: **気象庁（公用語: 気象庁 / 英語: Japan Meteorological Agency, 略称: JMA）**（国土交通省の外局、気象業務法に基づく国家気象機関）
- **陸上気象予報区・警報区の階層構造（気象庁防災情報XML / JSON `area.json` 準拠）**:
  1. **地方予報区（`centers` / 全11区域）**: 全国を11ブロックに分割する最上位区分（北海道地方`010100`、東北地方`020000`、関東甲信地方`030000`、北陸地方`040000`、東海地方`050000`、近畿地方`060000`、中国地方`070000`、四国地方`080000`、九州北部地方（山口県を含む）`090000`、九州南部・奄美地方`100000`、沖縄地方`110000`）。
  2. **府県予報区（`offices` / 全58区域）**: 管区気象台・地方気象台・測候所が管轄する基本予報単位。都府県は原則1都府県1区域（計45都府県）だが、面積が広大または離島を抱える3道県は細分化されている：
     - **北海道（7区域）**: 宗谷地方(`011000`)、上川・留萌地方(`012000`)、網走・北見・紋別地方(`013000`)、釧路・根室地方(`014100` ※十勝地方`014030`を内包または並列管理)、胆振・日高地方(`015000`)、石狩・空知・後志地方(`016000`)、渡島・檜山地方(`017000`)。※気象庁JSONの `offices` キーでは十勝地方を含む計8オフィスとして定義され、全国計**58区域**となる。
     - **鹿児島県（2区域）**: 鹿児島県（薩摩・大隅・種子島・屋久島地方 `460100`）と奄美地方（`460040`）。
     - **沖縄県（4区域）**: 沖縄本島地方(`471000`)、大東島地方(`472000`)、宮古島地方(`473000`)、八重山地方(`474000`)。
  3. **一次細分区域（`class10s` / 全142区域）**: 天気予報（今日・明日・明後日の天気）が発表される基本単位。府県予報区内を気候・地形特性により分割（例：東京都＝「東京地方(`130010`)」「伊豆諸島北部(`130020`)」「伊豆諸島南部(`130030`)」「小笠原諸島(`130040`)」の4区域）。
  4. **市町村等をまとめた地域（`class15s` / 全375区域）**: 一次細分区域と市区町村の中間階層（例：東京都東京地方＝「23区西部」「23区東部」「多摩北部」「多摩西部」「多摩南部」）。
  5. **二次細分区域（`class20s` / 全1,805区域）**: 気象警報・注意報・特別警報が発表される最小単位。原則として各市区町村単位（東京都特別区は各区単位、一部の広大な市町村は「〇〇市北部」「〇〇市南部」等に分割されているため、基礎自治体数1,741より多い1,805区域となる）。
- **海上予報区・沿岸警報区の体系**:
  - **全般海上警報区**: 北西太平洋および日本周辺の広域外洋海域（北緯0度〜60度、東経100度〜180度）。
  - **地方海上予報区（全12海域）**: オホーツク海南部、北海道東方海上、日本海北部、日本海中部、日本海西部、三陸沖、関東海域、東海海域、四国沖・紀伊水道、九州西方・東シナ海、南方海上、沖縄海域。
  - **沿岸海域（海上警報・波浪予報対象 / 全国74海域）**: 領海および内水（東京湾、相模湾、伊勢・三河湾、大阪湾、播磨灘、周防灘、有明海、八代海、陸奥湾、噴火湾等）を府県予報区の地先海岸ごとに74海域に区分し、波浪警報・高潮警報および沿岸波浪予想を発表。
  - **内水（湖沼）の扱い**: 琵琶湖（滋賀県）、霞ヶ浦（茨城県）、猪苗代湖（福島県）、宍道湖・中海（島根県・鳥取県）、サロマ湖・屈チャロ湖・支笏湖・洞爺湖（北海道）等の主要内水は、各該当一次細分区域・二次細分区域の強風・波浪注意報（湖上風浪）の対象に含まれる。

### 4.2 地上気象観測網と観測所地点リスト入手先
- **観測網の名称**: **地域気象観測システム（通称: アメダス / AMeDAS: Automated Meteorological Data Acquisition System）**（1974年11月1日運用開始）
- **観測所ネットワークの規模（現行稼働数: 1,286地点）**:
  - **区分別の内訳**:
    - 気象官署・特別地域気象観測所（旧測候所等、`type: A`）：**56地点**（または管区・地方気象台・航空測候所を含め約155地点）
    - 一般アメダス観測所（`type: C` 等）：**1,230地点**
  - **観測要素別の内訳（8桁要素フラグ `elems` による分類）**:
    - **4要素観測所**（降水量・気温・風向風速・日照時間＋湿度・気圧の一部）：**約840地点**
    - **雨量観測所**（降水量のみ観測）：**約446地点**
    - **積雪深計併設観測所**（豪雪地帯等の積雪深観測）：**約330地点**
- **観測所番号（5桁コード）の体系**:
  - 上2桁：都府県・北海道振興局別のブロック番号（`11` 宗谷 〜 `91` 沖縄本島・`94` 八重山）。
  - 下3桁：ブロック内の地点通し番号（北から南へ配列、例：宗谷岬 `11001`、稚内 `11016`、札幌 `14163`、東京 `44132`、那覇 `91197`）。
- **地点マスターデータの公式ダウンロードURL・ファイル形式・文字コード**:
  1. **気象庁防災情報 Web JSON（リアルタイム稼働地点マスター）**:
     - URL: `https://www.jma.go.jp/bosai/amedas/const/amedastable.json`
     - 形式・文字コード: `JSON` 形式、`UTF-8`。
     - 収録項目: 5桁地点コード、観測所種別（`type`）、8桁観測要素フラグ（`elems`）、緯度・経度（`[度, 分]` 形式）、標高（`alt` m）、漢字名（`kjName`）、カタカナ名（`knName`）、英語名（`enName`）。
  2. **気象庁公式「地域気象観測所一覧（アメダス地点情報履歴ファイル）」**:
     - URL: `https://www.jma.go.jp/jma/kishou/know/amedas/ame_master.zip` （一覧ページ: `https://www.jma.go.jp/jma/kishou/know/amedas/kaisetsu.html`）
     - 形式・文字コード: `CSV`（ZIP圧縮）、文字コード `Shift_JIS (CP932)`。
     - 収録項目: 都府県振興局、観測所番号（5桁）、種類、観測所名、カタカナ名、気象情報等に表記する名称、所在地住所、緯度（度・分）、経度（度・分）、海面上の高さ（m）、風速計の高さ（m）、温度計の高さ（m）、**観測開始年月日**、備考（移転・廃止履歴）。

## 5. 探索・GIS環境（オープンデータ規約・測地系・背景地図）

### 5.1 公的オープンデータのライセンスと測地系（CRS）
- **公的オープンデータの利用規約・ライセンス**:
  - **政府標準利用規約（第2.0版） / 公共データ利用規約（第1.0版 / PDL 1.0）**: 総務省、国土交通省（国土数値情報）、気象庁、e-Stat等の政府オープンデータに適用。**CC BY 4.0（クリエイティブ・コモンズ 表示 4.0 国際）と互換**であり、**出典の明記（例：「出典：国土数値情報（行政区域データ）を加工して作成」等）** を行えば、商用・非商用を問わず複製・加工・Webサイトでの一般公開・二次配布が適法に認められる。
  - **国土地理院コンテンツ利用規約**: 地理院タイルを背景地図としてWebサイトやアプリケーションに表示する場合、「国土地理院」または「地理院タイル」のクレジット表示（出典明記）のみで申請不要・無料で利用可能。
- **公式GISデータの標準測地系・投影法・EPSGコード**:
  - **日本測地系2011（JGD2011 / Japan Geodetic Datum 2011）**: 2011年東北地方太平洋沖地震に伴う地殻変動補正を反映した現行の法定測地系（測量法第11条）。地理座標系（経緯度）のEPSGコードは **`EPSG:6668`**（2002年〜2011年のJGD2000は `EPSG:4612`）。GRS80楕円体を採用しており、実用上 **WGS84（`EPSG:4326`）と数センチメートル以内で一致するため、座標変換なしでそのままWeb GISに投入可能**。
  - **平面直角座標系（I系〜XIX系）**: 大縮尺測量・公共測量で用いられるガウス・クリューゲル図法（`EPSG:6669` 〜 `EPSG:6687`）。
  - **旧日本測地系（Tokyo Datum / ベッセル楕円体、`EPSG:4301`）への注意**: 2002年3月以前の古い統計データや旧版地形図を参照する場合、現行の世界測地系（WGS84/JGD2011）と約400m（東京付近で北西へ約450m：緯度約+12秒、経度約-12秒）のズレがあるため、旧データ取り込み時は必ず座標変換（TKY2JGD等）を適用する。
