## 1. 道路網制度の詳細分類

### 1.1 道路法体系と詳細種別一覧

スイス連邦における道路網は、連邦憲法（SR 101）第83条および連邦国道法（Bundesgesetz über die Nationalstrassen: NSG, SR 725.11）に基づき連邦が所有・直轄管理する「連邦国道（Nationalstrassen）」と、各州（カントン: Kanton）および基礎自治体（ゲマインデ: Gemeinde）の法制下で管理される道路群に二大別される。連邦国道（Nationalstrassen）は単なる高速道路の別称ではなく、スイス全土および国際的な連絡機能を果たす最重要幹線を連邦議会決定（Netzbeschluss, SR 725.113.11）によって指定した法的ネットワークであり、構造規格と交通規制に応じて第1級から第3級までの3段階に分類される。一方、連邦国道網に属さない主要道路（Hauptstrassen）は、連邦の通過道路令（SR 741.272）および鉱油税目的税法（MinVG, SR 725.116.2）により連邦財政補助の対象となるものの、施設所有権および管理権は各カントンに帰属する。

連邦国道法第2条の規定により、第1級連邦国道（Autobahn）は自動車専用であり、上下線が構造的に分離され、片側2車線以上を有し、平面交差を一切持たず専用連結路（Anschlussstellen）からのみ出入り可能な最高規格道路として定義され、法定最高速度は原則120 km/hに設定されている。同法第3条に定める第2級連邦国道（Autostrasse）は、同じく自動車専用かつ専用連結路からのみアクセス可能で原則として立体交差化されているものの、上下非分離（対面通行）または片側1車線構造をとる路線であり、山岳部やアルプス縦貫ルート（A2ゴッタルド道路トンネル区間、A13サン・ベルナルディーノ区間等）に多く存在する。同法第4条に定める第3級連邦国道は、自動車以外の通行にも開放された一般道路規格の連邦直轄路線であるが、集落バイパス化や平面交差の排除が優先的に図られる。また、総重量3.5トン未満の自動車およびトレーラーが第1級・第2級連邦国道を通行する際には年間40スイスフランの高速道路通行証（Vignette：12月1日から翌々年1月31日までの14ヶ月間有効）が義務付けられ、3.5トン以上の重量車両には走行距離・重量・排出ガス性能に応じた重量車課金（LSVA）が適用されるため、別途のVignette購入は不要となる。

### 1.2 付番ルール・管理者・OSMタグ対照表

スイスの道路付番体系における最大の制度的特徴は、連邦国道の「行政内部管理番号（N番号: N-Nummern）」と「対外案内・標識番号（A番号: A-Nummern）」の二重管理構造、および主要道路（Hauptstrassen）の「青地白文字番号」の階層分離にある。対外的な道路標識（赤地白文字の六角形盾マーク）、地図表記、交通情報等では「A番号（A1〜A24、およびカントン管理のA50〜A53等）」が排他的に使用される。このA番号は道路構造クラスを横断して第1級（Autobahn）と第2級（Autostrasse）の双方に機能的に付与されるため、Aプレフィックスのみでは第1級か第2級かは判別できず、緑地の高速道路案内標識か青地の一般道路案内標識か、およびAutobahn/Autostrasseのピクトグラム標識によって区別される構造となっている。また、複数路線が重複する共用区間には必要なすべてのA番号が割り当てられる。

これに対し、「N番号（N1〜N29）」は連邦国道網決定（Netzbeschluss, SR 725.113.11）および連邦道路局（ASTRA）の内部台帳・工事プロジェクト管理（N1b, N1c等）において、連邦直轄道路とカントン道路を法的に区別するために使用される行政番号である。例えば、連邦国道網決定に基づきカントンから連邦へ移管された路線群（N20 Le Locle–La Chaux-de-Fonds–Tunnel de la Vue des Alpes–Neuchâtel等）は、内部管理上は第3級連邦国道区間も含めて「N番号」で統一管理され、そのうちAutobahnまたはAutostrasse規格の区間が対外的に「A番号（A20等）」として案内される。さらに下位の主要道路（Hauptstrassen）については、通過道路令（SR 741.272）に基づき全国で1番から471番までの番号が定義されており、国土を縦横断する長距離幹線・主要峠越え路線に1桁〜2桁番号（1〜30）、地域間連絡幹線に3桁番号（101〜471）が付与される。現地標識ではプレフィックスなしの「青地白文字の数字のみ」で表示されるが、行政文書やGISデータベースでは連邦国道との混同を避けるため便宜的に `H1`, `H2` 等と表記される。さらに各カントンが管理するカントン道（Kantonsstrassen）には各州独自の道路台帳番号が付与されるが、現地案内標識には表示されずキロポスト（距離標）のみで管理されるケースが大半である。

OpenStreetMap（OSM）およびスイス国内のGIS解析における道路クラス分類では、`highway=motorway`（および `motorway_link`）と `highway=trunk`（および `trunk_link`）が「クラス1（高速道路・自動車専用道路網）」として扱われ、`highway=primary`（および `primary_link`）が「クラス2（主要道路網：Hauptstrassen）」として明確にマッピングされている。連邦直轄管理区間（ASTRA）とカントン管理区間の分担については、2008年1月1日に発効した「連邦と州の財政調整および役割分担の新秩序（NFA）」および連邦国道法第8a条に基づき、稼働中の連邦国道（Nationalstrassen）の所有権・維持管理権・運営権がカントンから連邦（ASTRA）へ無償かつ完全に移管されている。既存のカントン道路が新たに連邦国道網（Netzbeschluss）に編入された場合も、編入時点で所有権が連邦へ無償移転する一方、連邦国道網から除外された道路はカントンへ移管される。ただし、1960年の連邦国道網決定（SR 725.113.11）で定義されたものの未完成となっている新規建設区間（Netzvollendung）については、ASTRAの行政指針（ASTRA 7A100および11004）の下で関係カントンが建設事業主体を担い、完成後に連邦へ引き渡す分担体制がとられている。なお、連邦国道網のボトルネック解消プログラム（STEP Nationalstrassen：Ausbauschritt 2023）は2024年11月24日の国民投票において反対52.7%で否決されたため、今後のインフラ計画は既存承認済み枠組みおよびボトルネック解消モジュール1〜4の再評価の下で進められる見通しにある。

## 2. 鉄軌道・都市交通・索道制度の詳細分類

### 2.1 鉄軌道・都市交通・索道の法体系一覧

スイスの鉄軌道・都市交通・索道法制は、インフラの技術的・安全規制的根拠を定める法律と、公共交通としての運行権利・義務（時刻表公表義務、タリフ統合義務、運送引受義務）を定める「連邦旅客運送法（Personenbeförderungsgesetz: PBG, SR 745.1）」の二層構造によって統制されている。鉄軌道（標準軌・狭軌・ラック式・路面電車・地下鉄）はすべて「連邦鉄道法（Eisenbahngesetz: EBG, SR 742.101）」の単一法体系下に置かれており、路面電車やLRTもEBG傘下の鉄道令（EBV）における技術基準区分として規律される。一方、ケーブルカー（鋼索鉄道）およびロープウェイ（空中索道）は「連邦索道法（Seilbahngesetz: SebG, SR 743.01）」によって規律されるが、このうちPBGに基づく連邦旅客運送認可（Personenbeförderungskonzession）を連邦運輸局（BAV）から付与された路線（通年居住集落のアクセスを担う路線や都市内公共交通として機能する路線）は、鉄道やバスと完全に同格の「連邦認可公共交通機関」として全国時刻表（Kursbuch）およびGTFSデータに統合される。

## 3. バス事業制度の詳細分類

### 3.1 自動車運送事業法に基づく法的区分一覧

スイスにおけるバス事業は、連邦旅客運送法（PBG, SR 745.1）および旅客運送令（VPB, SR 745.11）の下で「連邦認可（Konzession）に基づく定期旅客運送」として一元管理されており、道路上のバス路線であっても鉄道と同一の法体系・補助金スキーム・時刻表公表義務（Publikationspflicht）が適用される。特に農山村部やアルプス山岳地域における地域旅客輸送（Regionaler Personenverkehr: RPV）では、スイス郵便（Die Schweizerische Post）傘下の「ポストバス（PostAuto AG / 仏: CarPostal / 伊: AutoPostale）」が全国の鉄道駅から分岐するフィーダー網および山岳峠越え路線を広く運行しており、各都市の公営交通バスや地域鉄道会社系のバス部門とともに、カントン単位または都市圏単位の「広域運輸連合（Tarifverbund / Verkehrsverbund）」に完全統合されている。

## 6. 交通拠点（ノード）の詳細種別と公式コード

スイスの公共交通データ基盤における最大の制度的・技術的強みは、鉄道駅、トラム電停、バス停留所、ケーブルカー・ロープウェイ駅、湖沼の船着場、さらには空港連絡拠点に至るまで、国内のすべての公共交通拠点（Dienststellen / Service Points）が連邦運輸局（BAV）の監督する単一の公式識別コード体系によって完全に一元管理されている点にある。BAVの委託を受け、スイス連邦鉄道（SBB Infrastruktur）が全国の輸送事業者のために運用する国家マスターデータシステム「ATLAS（旧称：DiDok = Dienststellen-Dokumentation）」において、すべての拠点に「DIDOKコード（`BPUIC`：Betriebspunkt-UIC）」が付番されている。このDIDOKコードの基本フォーマットは7桁の数値（`85xxxxx`）であり、先頭2桁がUIC国コード「`85`（スイス）」、続く5桁が拠点固有番号（`00000`〜`99999`）で構成され、鉄道駅とUIC駅コード（UIC-Haltestellencode）が完全に同一の番号空間を共有している。鉄道駅（例：`8503000` = Zürich HB、`8506038` = Winterthur Wallrüti）だけでなく、バス停やトラム電停（例：`8578157`、`8589334`）、船着場にもすべて `85xxxxx` が割り当てられ、さらに駅構内の個別ホーム（番線：Gleis）やバスの乗り場（Haltekante / Steig）を識別する際には、7桁のBPUICの末尾に2桁の「Haltepunktcode（例：`02`）」を付加した9桁コード（例：`850300002`）が使用される。また、鉄道駅および主要拠点には2〜5文字の公式アルファベット略称（Abkürzung / BPS、例：`ZUER` = Zürich、`BN` = Bern、`SIT` = Sitten/Sion）が定義されている。

さらに2026年6月からは、`opentransportdata.swiss` で配信されるGTFS（`stops.txt` の `stop_id`）およびOJP（Open Journey Planner）において、親拠点から個別の乗車位置（Steig / Haltekante）までを厳密に階層表現する次世代標準識別子「SLOID（Swiss Location ID）」が本格導入された。SLOIDは拠点単位が `ch:1:sloid:91315`、個別乗り場（Steig）単位が `ch:1:sloid:7000:6:32` のようなコロン区切り文字列で構成されるが、GTFSデータ内では従来の7桁DIDOKコードも併せて保持されており、双方向の参照性が担保されている。なお、スイス国内の鉄道・トラム・地下鉄には日本のような旅客案内用の駅ナンバリングは存在せず、すべての運行系統に付与された路線・系統番号（例：`IC 1`, `S29`, `Tram 8`）と「`自治体名, 停留所名`」の標準命名規則によって案内が行われる。一方、道路網における高速道路施設については、連邦国道（`A1`〜`A24`）上のインターチェンジ（`Anschlussstelle`）およびジャンクション（`Verzweigung`）に起点から連番の出口番号が付番され、休憩施設は連邦国道法第7条に基づくフルサービスのサービスエリア（`Raststätte`）と同法第7a条に基づく簡易パーキングエリア（`Rastplatz`）に法的に区分されている。

## 7. 路線の繋がり（順序）の公式基準 ＆ 駅順データ調達

スイスにおける鉄軌道・公共交通路線のトポロジー（起点〜終点の方向性および駅・停留所の並び順）は、インフラ管理上の物理路線基準（Kilometrierung / Linienprofile）と旅客運行系統上の時刻表基準（INFO+ / GTFS / Kursbuch）の双方で完全なオープンデータとして整備・公開されている。インフラ物理路線基準としては、SBB Infrastrukturがオープンデータポータル（`data.sbb.ch`）において週次更新で公開している「路線別キロ程点（`linienkilometrierung`）」および「運営拠点付き路線（`linie-mit-betriebspunkten`）」が最も権威ある公式基準となる。このデータセットでは、標準軌幹線（`Basel SBB - Olten - Luzern` 948ポイント、`Daillens - Biel/Bienne` 852ポイント、`Altdorf - Lugano` 646ポイント等）だけでなく、狭軌鉄道や山岳路線（`Brig - Andermatt - Disentis` 951ポイント、`Brig - Visp - Zermatt` 438ポイント、`Forchbahn ZUER - ESSL` 131ポイント等）に至るまで、現地沿線のキロポスト標識と完全一致するキロ程値（`KM`）と、その路線上に位置する全拠点（`Betriebspunkte`：DIDOKコード `85xxxxx`）の空間的順序が定義されている。

一方、旅客運行系統上の公式路線網台帳・時刻表・GTFSデータについては、BAVから「顧客情報システム管理（Systemaufgaben Kundeninformation: SKI+）」の委任を受けたSBBが運営する全国オープンプラットフォーム `opentransportdata.swiss` に完全集約されている。同プラットフォームの背後では、全輸送事業者が100%データを提出している停留所・事業組織マスター「ATLAS（旧DiDok）」および全国統合時刻表データベース「INFO+」と、リアルタイム予測・遅延ハブ「CUS」の3大国家基幹システムが稼働している。INFO+からは毎週1回（週次更新）、現行ダイヤ（`timetable-2026-gtfs2020`）、次期ダイヤ（`timetable-2027-gtfs2020`）、ドラフトダイヤがGTFS Static、HRDF（HAFAS Rohdatenformat）、および欧州標準NeTEx形式で自動出力される。したがって、GTFS Staticの `routes.txt`（DIVA識別子または次世代 `SLNID: Swiss Line ID`）、`trips.txt`、`stop_times.txt` を結合し `stop_sequence` 順にソートすることで、スイス国内のすべての鉄道・トラム・地下鉄・バス・ケーブルカー・定期航路の正確な駅順エッジを単一パッケージから一括調達できる。また、CUSからはGTFS-Realtime（`Trip Update` v1.0、`Service Alerts` v2.0）および前日の実績運行データ（`IST-Daten`）が配信されている。
