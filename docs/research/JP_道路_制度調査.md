# 日本 (JP) 道路制度調査シート（主要地方道・高速・国道）

- 作成日: 2026-10-15
- 目的: 主要地方道および道路網の公的制度・付番規則・出典元を調査し、抜け漏れや過剰取得のない厳格な収集仕様を確立する。
- 参照根拠: 道路法第56条、平成5年5月11日建設省告示第1270号、平成6年6月30日建設省道政発第33号通達

---

## 1. 道路分類と公的基準

| 道路種別 | 法的根拠 / 制度 | 管理主体 | 全体規模（基準値） | 収集方針 |
| :--- | :--- | :--- | :---: | :--- |
| **高速自動車国道** | 高速自動車国道法 | 国（NEXCO各社等に管理委託） | 約100路線 | 全線取得（ナンバリング・愛称付与） |
| **都市高速道路** | 道路法（自動車専用道路） | 各高速道路公社（首都高・阪神高等） | 約120路線 | 全路線取得 |
| **一般国道** | 道路法第5条 | 国（国土交通省）／指定市 | **459路線** | 1号〜507号（欠番48除外）全線取得・完全一致 |
| **主要地方道** | **道路法第56条** | **各都道府県 ／ 政令指定都市** | **約4,000〜4,500路線**<br>（各県30〜150路線程度） | **全都道府県の指定路線のみ抽出** |
| **一般都道府県道** | 道路法第7条 | 各都道府県 | 数万路線 | **初期自動収集は除外**（探索時個別追加） |
| **農道・林道** | 土地改良法 / 森林法 | 市町村・土地改良区・森林組合 | 多数 | **初期自動収集から完全削除** |

## 2. 主要地方道 (都道・道道・府道・県道) の付番ルールと例外

### 2.1 全国標準ルール（建設省道政発第33号通達）
1994年（平成6年）の建設省道路局長通達「第七 路線番号のつけ方」に基づき、全国の都道府県道は原則として以下の基準で採番されている：
- **主要地方道（主要都道府県道）**: **1号 〜 100号**
- **一般都道府県道**: **101号以降**（各県により101〜、200〜、300〜等）

### 2.2 重大な例外と都道府県別特性

| 都道府県 | 主要地方道の付番範囲 | 特記事項・旧スクリプトの欠陥原因 |
| :--- | :--- | :--- |
| **北海道** | **1号 〜 151号**（主要道道） | **【重大欠陥】旧スクリプトで0件だった**。<br>理由1: カテゴリ名が「北海道道」であり「県道」の文字列に引っかからなかった。<br>理由2: Wikipediaでは `Category:北海道道 (主要道道)` のサブカテゴリに151路線がまとめられていたが、直下しか取得していなかった。<br>理由3: 番号が151号まで及ぶため、「120番以下」ルールでは121〜151号が欠落する。 |
| **東京都** | **1号 〜 68号**（主要都道）<br>＋ **301号 〜 319号**（特例主要都道） | 300番台（新奥多摩街道、永代通り等）は「特例都道である主要地方道」として指定されている。<br>※400番台・500番台は一般特例都道のため除外が必要。 |
| **神奈川県** | 2号 〜 78号（主要県道）<br>＋ 横浜市・川崎市主要地方道 | 神奈川県道1号は欠番。横浜市道・川崎市道の主要地方道が存在。 |
| **大阪府** | 1号 〜 99号（主要府道） | 大阪府道・京都府道・兵庫県道は「1〜99」が主要地方道。 |
| **京都府** | 1号 〜 80番台（主要府道） | 100番台以降は一般府道。 |
| **山梨県** | 1号 〜 43号 | 主要県道は40番台前半まで。一般県道は100番台〜。 |
| **その他40県** | **1号 〜 80〜90番台** | 各県の「〇〇県の県道一覧」における「主要地方道」セクション、または番号1〜99番台が対象。 |

## 3. 正確な抽出仕様（スクリプト改修方針）

### 3.1 抽出元の確定
1. **北海道**: `Category:北海道道 (主要道道)` の全記事（151路線）を網羅取得。
2. **東京都**: `東京都の都道一覧` から「主要地方道 (1 - 68)」および「特例都道である主要地方道（301-319）」を抽出。
3. **その他45府県**:
   - `Category:〇〇県道`（または府道）から番号が **1号〜99号** の路線を抽出。
   - `cmlimit=500` かつ継続トークン（`cmcontinue`）による全件走査を実装し、取りこぼしを根絶。
   - 廃止路線カテゴリ（`Category:〇〇県道 (廃止)` 等）は厳格に除外。

### 3.2 排除・削除の徹底
- **林道（84件）および農道（351件）**: 抽出ロジック（`fetch_farm_and_forest_roads`）をスクリプトから完全に削除。
- **外国混入の遮断**: 収集時に日本の座標境界（緯度20.0〜46.0、経度122.0〜154.0）外のデータ、またはタイトルに海外地名が含まれるデータを即座に破棄。
- **ID永続化マネージャー連携**: `IdManager` を介して既存IDを維持し、新規のみ採番。
