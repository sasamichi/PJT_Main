## 1. 対象国基本情報・地理的範囲

- **国名（日本語 / 公用語 / 英語）**: 大韓民国（韓国） / 대한민국 / Republic of Korea
- **ISO 3166-1コード**: Alpha-2: `KR`, Alpha-3: `KOR`, 数値: `410`
- **公用語（地域的公認言語を含む）**: 韓国語（한국어：国語基本法に基づく公用語）、韓国手話言語（한국수화언어：韓国手話言語法に基づき韓国語と同等の資格を有する公用語）、済州語（제주어：済州特別自治道の「済州語保全及び育成条例」に基づく地域公認・保全言語）
- **国家体制**: 単一国家・大統領制共和国であり、地方自治法第2条に基づき、広域自治団体（第1階層：特別市1、広域市6、特別自治市1、道6、特別自治道3の計17団体）と基礎自治団体（第2階層：市75［うち特例市5］、郡82、自治区69の計226団体）の2層制地方自治構造をとる。
  - 例外的な単層または準単層構造として、世宗特別自治市は傘下に基礎自治団体を置かず直下に邑・面・洞を配置し、済州特別自治道は傘下に法人格を持たない非自治の「行政市（행정시）」2市（済州市・西帰浦市）を置く体系を採用している。
  - また、地方自治法第3条第3項および第198条に基づき、人口100万人以上の特例市および人口50万人以上の一般市は、その傘下に自治権を持たない「一般区（行政区）」を設置して都市行政事務を分掌させている。
- **領土バウンディングボックス（経緯度範囲）**:

### 2.2 国勢調査・統計調査区の体系（将来用ストック）

- **所管統計機関名・公式ポータルURL**: 統計庁（KOSTAT、`https://kostat.go.kr/`）、国家統計ポータル（KOSIS: `https://kosis.kr/`）、統計地理情報サービス（SGIS: `https://sgis.kostat.go.kr/`）、統計分類ポータル（KSSC: `https://kssc.kostat.go.kr/`）。
- **基礎自治体より細かい統計調査単位の階層構造・単位名称・件数規模**:
  - 国勢調査（人口住宅総調査）は法定洞ではなく「行政洞（邑・面・行政洞、全国約3,522区域）」を基本集計単位として運用。
  - **集計区（집계구 / Output Area: OA）**: 全国約110,500区域（14桁コード）。最適人口500人（300〜1,000人）基準。
  - **基礎単位区（기초단위구 / Basic Unit District）**: 全国約480,000区域。恒久的地形地物で囲まれた最小空間ブロック。
  - **地域メッシュ統計（SGIS 격자통계）**: 標準平面直角座標系UTM-K（`EPSG:5179`）に基づく国家地点番号グリッド体系（100km、10km、1km、500m、250m、100mの6段階）。
- **境界データ入手先URL・更新頻度**: SGIS資料提供（`https://sgis.kostat.go.kr/view/pss/openDataIntrcn`）および公共データポータル（`https://www.data.go.kr/`）から、試道・市郡区・邑面洞・集計区・基礎単位区のShapefile（座標系 `EPSG:5179`）が無償配布。年1〜2回定期更新。

### 2.3 「政庁所在地（役所・庁舎の点座標）」の公式定義とデータ有無

- **公式座標の仕様**: 行政領域ポリゴンの幾何学的重心（Centroid）だけでなく、各自治体の本庁舎（道庁、特別・広域市庁、市庁、郡庁、区庁）および下部行政機関（邑・面事務所、行政福祉センター）の**正確な建物位置座標（Point）および建物外郭ポリゴン**が公的オープンデータとして提供されている。
- **入手方法**:
  1. 行政安全部「住所情報ヌリジプ（`https://business.juso.go.kr/`）」の「位置情報要約DB（TXT）」および「道路名住所電子地図（SHP）」に庁舎の建物中心点座標（`EPSG:5179`）、住所、法定洞・行政洞コードが収録（毎月更新）。
  2. 公共データポータル（`https://www.data.go.kr/`）の「全国住民センター（行政福祉センター）標準データ」「全国地方自治団体庁舎位置データ」（WGS84経緯度 `EPSG:4326` 付きCSV/JSON/API）。

## 3. 公式コード体系とWikidataプロパティ

### 3.1 国内公式コード（自治体コード・統計区コード）

- **コード規格名、桁数ルール、体系の仕組み**:
  - **法定洞コード（10桁固定）**: 試道(2) + 市郡区(3) + 邑面法定洞(3) + 法定里(2)。土地・地籍・登記・地番住所用。
  - **行政機関・行政洞コード（10桁固定）**: 試道(2) + 市郡区(3) + 邑面行政洞(3) + 00(2)。住民登録人口統計・住民センター管轄用。
  - **統計庁行政区域コード（8桁体系）**: 試道(2) + 市郡区(3) + 邑面行政洞(3)。国勢調査・SGIS境界用。
  - **重要留意事項**: **統計庁コードは行政安全部コードと先頭2桁（試道）および市郡区コードの番号割当がソウル（11）を除き全く異なる独自体系**（例: 釜山は行安部 `26` に対し統計庁 `21`、京畿道は行安部 `41` に対し統計庁 `31`）。SGISポリゴンと行安部データを結合する際は必ず公式マッピング表（KSSC）による変換が必須。
  - **集計区コード（14桁固定）**: 統計庁コード(8) + 集計区連番(6)。
- **最新版コードリストの入手先**:
  - 行政安全部「行政標準コード管理システム」: `https://www.code.go.kr/`（法定洞コードTXT）
  - 行政安全部公式サイト: `https://www.mois.go.kr/`（行政洞・法定洞N対Mマッピング表 `KIKmix` Excel）
  - 統計庁「統計分類ポータル」: `https://kssc.kostat.go.kr/`（統計庁8桁⇔行安部10桁変換テーブルExcel）

## 4. 気象機関・予報区・観測網

### 4.1 国家気象機関と予報区体系（陸上および海上）

- **国家気象機関名**: 기상청 / Korea Meteorological Administration (KMA) / 大韓民国気象庁 / 公式サイト: `https://www.weather.go.kr/` / APIハブ: `https://apihub.kma.go.kr/` / オープンデータ: `https://data.kma.go.kr/`
- **陸上気象予報区の階層構造**:
  - 第1階層: **広域予報区域（19区域）**。中期予報・広域概況発表単位。江原道を嶺西・嶺東に分割、西海5島、鬱陵島・独島を分離。
  - 第2階層: **陸上気象特報区域（183区域、細分時約235区域）**。気象注意報・警報発令単位。ソウル4圏域、江原山岳3分割、済州漢拏山標高別10分割（山地、中山間、沿岸等）。
  - 第3階層: **短期・村落予報区域（約3,550区域）**。邑面洞単位および5km×5km（超短期1km×1km）格子点（Grid `nx`, `ny`）で配信。
  - データ提供: 気象庁APIハブおよび公共データポータルにてREST API（JSON/XML）および特報区域境界Shapefileを提供。
- **海上予報区・沿岸警報区**:
  - 西海・南海・東海の3大海域を北部・中部・南部に区分。
  - 沿岸12海里以内の「前海（앞바다 / Inshore）」、沖合の「内側遠海（안쪽먼바다）」、遠洋の「外側遠海（바깥먼바다）」の3段階で波浪・強風特報を発令。

### 4.2 地上気象観測網と観測所地点リスト入手先

- **観測網の名称**: **総観気象観測網（ASOS: Automated Synoptic Observing System）**および**防災気象観測網（AWS: Automatic Weather System）**。
- **観測所規模（地上観測総数約615〜630地点）**:
  - **ASOS（総観気象観測）**: 全国**105地点**（気象台・観測所）。気圧・気温・湿度・風向風速・降水量・日照・日射・積雪等を毎分・毎正時観測。
  - **AWS（防災気象観測）**: 全国**約510〜525地点**。市郡邑面・山岳・島嶼に高密度配置（気温・降水・風向風速・湿度・気圧等を自動観測）。
- **地点マスターデータの入手先**:
  - 気象資料開放ポータル「観測地点情報」: `https://data.kma.go.kr/tmeta/stn/selectStnList.do`（全観測網の地点番号、地点名、WGS84経緯度、標高、住所マスターCSV/Excel）。
  - 気象庁APIハブ（`https://apihub.kma.go.kr/`）にて地点番号（`stnIds`）をキーにリアルタイム観測値を取得可能。

### 5.2 標準測地系・投影法・EPSGコード

- **標準測地系**: **Korea 2000（KGD2000 / 準拠楕円体: GRS80）**。WGS84（`EPSG:4326`）と実用上同一（数cm以内）であり無変換可能。旧測地系Korean 1985（Bessel楕円体 `EPSG:5174` 等）にはBursa-Wolf 7パラメータ変換が必須。
- **平面直角座標系（重要留意事項）**:
  - 全国単一投影: **`EPSG:5179`（UTM-K）**。統計庁SGIS、行政安全部Juso.go.kr標準。
  - 4原点帯投影: 国土地理情報院・V-World標準 **`EPSG:5185`〜`5188`（2010年改定版：偽北距 600,000m）**。旧定義 `EPSG:5181`〜`5184`（偽北距 500,000m）と100kmのズレがあるため指定誤りに注意。

### 5.3 公式背景地図タイルとストリートビュー・パノラマカバレッジ状況

- **公式背景地図タイル（V-World WMTS/XYZ）**:
  - 無料APIキー（`{API_KEY}`）により `EPSG:3857` タイルを利用可能。
  - 基本道路・建物地図: `https://api.vworld.kr/req/wmts/1.0.0/{API_KEY}/Base/{z}/{y}/{x}.png`
  - 高解像度衛星・航空写真: `https://api.vworld.kr/req/wmts/1.0.0/{API_KEY}/Satellite/{z}/{y}/{x}.jpeg`
  - 透過ハイブリッド注記: `https://api.vworld.kr/req/wmts/1.0.0/{API_KEY}/Hybrid/{z}/{y}/{x}.png`
  - 白地図: `https://api.vworld.kr/req/wmts/1.0.0/{API_KEY}/white/{z}/{y}/{x}.png`
- **ストリートビュー各社のカバレッジ状況**:
  - **Google ストリートビュー**: 大都市圏や主要道路をカバーするが、地方部や細街路の更新頻度は低い。国家安保法・地図持ち出し規制により軍事・保安施設のブラー・マスク処理が義務付けられている。
  - **Apple Look Around（Apple Maps）**: 韓国公道上のパノラマ画像は**未提供（カバレッジなし）**。
  - **Yandex パノラマ / 百度全景**: いずれも**カバレッジなし（未提供）**。
  - **Mapillary / KartaView**: ユーザー投稿画像が首都圏や幹線道路に断片的にあるのみで網羅性は低い。
  - **現地独自サービス（Naver Map / Kakao Map）**: **圧倒的な国内シェアと完全な網羅性（ほぼ100%カバー）**。
    - **Naver Map「ストリートビュー（거리뷰）」**（`https://map.naver.com/`）
    - **Kakao Map「ロードビュー（로드뷰）」**（`https://map.kakao.com/`）
    - 両サービスとも高速・国道・地方道だけでなく、路地裏（バックパック撮影）、登山道、全離島（済州・鬱陵・独島・白翎等）までカバー。高頻度更新・タイムマシン機能・全天球航空ビューを完備。机上探索の第一選択肢となる。
