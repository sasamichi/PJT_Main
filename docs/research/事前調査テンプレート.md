# 国別現行制度・データ調達設計 事前調査テンプレート

新しい国・地域のデータ収集を行う前に、本テンプレートおよび [`.agents/skills/country-pre-research/SKILL.md`](../../.agents/skills/country-pre-research/SKILL.md)（**※必ず1行目〜最終行まで全文を読了すること**）に従って現地現行制度、行政階層、道路・鉄道体系、コード規格、データ調達条件、出典メタデータを調査し、`docs/research/[国コード]_行政・気象_制度調査.md` および `docs/research/[国コード]_交通_制度調査.md` として保存すること。

## 調査の分割方針と厳格制約
1. **「行政・統計・気象編」** と **「交通編」** の2ファイルに分割して調査・管理する。
2. **過去の変遷・沿革・廃線廃駅史は一切排除**し、現行最新の有効な制度・施設・データ調達条件に特化する。
3. **政治・経済・環境エッセイ・商業店舗分析は一切排除**し、客観的な「台帳（法規・数値・コード・URL）」に徹する。
4. 初期収集対象外の種別（農道、林道、スキーリフト、工場専用線、貸切バス等）は**一覧表に1行記載するのみとし、本文解説は省略**する。
