# 国別制度・変遷 事前調査テンプレート

新しい国・地域のデータ収集を行う前に、本テンプレートおよび [`.agents/skills/country-pre-research/SKILL.md`](../../.agents/skills/country-pre-research/SKILL.md)（**※必ず1行目〜最終行まで全文を読了すること**）に従って現地公的制度、行政階層、道路・鉄道体系、コード規格を調査し、`docs/research/[国コード]_行政・気象_制度調査.md` および `docs/research/[国コード]_交通_制度調査.md` として保存すること。

本調査結果は「データ精度管理表（基準件数）」および「公的オープンデータ取得・フィルタ条件」の直接の根拠となり、Webサイトの百科事典コンテンツ（制度ナレッジ）としても公開される。

## 調査の分割方針と厳格制約
1. **「行政・気象編」** と **「交通編」** の2ファイルに分割して調査・管理する。
2. **政治・経済・環境エッセイ・商業店舗分析は一切排除**し、客観的な「台帳（法規・数値・コード・URL）」に徹する。
3. 初期収集対象外の種別（農道、林道、スキーリフト、工場専用線、貸切バス等）は**一覧表に1行記載するのみとし、本文解説は省略**する。
4. 「OSM道路ランク国際対応表」や「UN/LOCODE」は国別事前調査とは別工程で一括管理し、「国際路線対応・重複区間ルール・軌間等の路線スペック」は路線データ収集工程で扱う。
