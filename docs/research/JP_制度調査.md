### 2.2 過去の変遷・制度改革の歴史
- **明治の市制・町村制（1889年 / 明治の大合併）**: 全国約71,000町村が15,859市町村に統合。
- **昭和の大合併（1953年〜1961年）**: 市町村数が約9,868から3,472へと激減。
- **平成の大合併（1999年〜2010年頃）**: 合併特例法に基づき、全国3,232市町村が約1,700自治体に半減。
- **直近の再編（2024年1月1日 浜松市行政区再編）**: 従来の7区（中区・東区・西区・南区・北区・浜北区・天竜区）が3区（中央区・浜名区・天竜区）へ再編。政令市行政区が175区から**171区**へ。

### 2.3 今後数年内に予定されている大規模な制度変更・再編
- **全国的な制度変更の有無**:
  - 全国規模の合併推進策、道州制への移行、大阪都構想などの広域自治体改編は、直近数年内に施行予定のものはない。
  - 個別市町村の単独市制施行（例: 人口5万人突破による町から市への昇格検討等）はあるが、全体のコード体系を揺るがす変更は予定されていない。

## 3. 公式コード体系

### 3.1 国内公式コード（自治体・地域コード）
- **コード規格名**: **全国地方公共団体コード（JIS X 0401 / JIS X 0402）**
- **コード体系・桁数**:
  - **6桁コード**: 上2桁（都道府県コード `01`〜`47`）＋ 次3桁（市区町村番号 `100`〜）＋ 末尾1桁（モジュラス11ウェイトによるチェックディジット）。
  - ※政令指定都市は末尾が `000`（例: 札幌市 `011002`）、その下位の行政区は `101`〜`110` 等が割り当てられる。
- **最新版コードリストの入手先**:
  - **総務省**: 「全国地方公共団体コード」ページにて常時最新のExcel・CSVがダウンロード可能。
    - URL: `https://www.soumu.go.jp/denshijiti/code.html`
  - **J-LIS（地方公共団体情報システム機構）**: 自治体コード表（最新版）。
- **過去分・変遷履歴コードリストの入手先**:
  - **e-Stat（政府統計の総合窓口）**: 「市区町村名・コード」「廃置分合等情報」にて、1970年（昭和45年）以降の任意の時点のコードおよび新旧対照データをCSVダウンロード可能。
    - URL: `https://www.e-stat.go.jp/`
  - **J-LIS 改正一覧表**: 平成17年（2005年）以降の自治体コード新旧対照表（PDFアーカイブ）。

### 3.2 国際標準コード
- **ISO 3166-2:JP**: `JP-01`（北海道）〜`JP-47`（沖縄県）。
- ※UN/LOCODE等は別調査で集約するため本シートでは割愛。

## 5. 気象機関・観測網（将来の気象データ連携用）

### 5.1 国家気象機関と予報区体系
- **国家気象機関**: **気象庁 (Japan Meteorological Agency / JMA)**
- **予報区の階層構造**:
  1. **地方予報区**: 全国11地方（北海道、東北、関東甲信、北陸、東海、近畿、中国、四国、九州北部、九州南部・奄美、沖縄）。
  2. **府県予報区**: 原則として都府県単位（北海道は宗谷、上川・留萌など7方面に細分）。
  3. **一次細分区域**: 都府県内を気候・地形特性に応じて数個に分割（例: 静岡県＝「伊豆」「東部」「中部」「西部」）。
  4. **市町村等をまとめた地域（二次細分区域）**: 注意報・警報の発表基準単位。

### 5.2 地上気象観測網（アメダス）
- **観測網名称**: **アメダス (AMeDAS / 地域気象観測システム)**
- **規模**: 全国約1,300箇所。
  - 4要素観測所（降水量、風向風速、気温、日照時間）：約840地点。
  - 積雪計併設（豪雪地帯）：約330地点。
  - 降水量のみ観測：約460地点。
- **観測地点マスターの入手先**:
  - 気象庁公式「アメダス地点情報履歴ファイル」: `https://www.jma.go.jp/jma/kishou/know/amedas/ame_master.zip`
  - 収録項目: 観測所番号（5桁）、観測所名（漢字・カナ）、所在地（住所）、緯度・経度、標高、開始・廃止年月日。
