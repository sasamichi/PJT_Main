# 世界交通網・地域データ基盤（仮） (Global Transit & Territory Archive)

世界じゅうの過去から現在まで存在・計画された「交通網」と「国・地域・区域」のデータを収集・整理し、1つにまとめた統合データ基盤アーカイブです。

---

## 🌐 公開Webサイト

本プロジェクトの一般公開Webサイトは、GitHub Pagesを通じて以下のURLで先行公開（α版）されています。

🔗 **公開URL**: [https://sasamichi.github.io/PJT_Main/](https://sasamichi.github.io/PJT_Main/)

---

## 🗺️ 主な機能と収録コンテンツ（α版先行公開仕様）

1. **🏠 ホーム画面（プロジェクト案内・更新情報）**
   - プロジェクトの目的、α版先行公開の案内、公式注記・免責事項。
   - 画面遷移時のちらつき防止処理済み。
2. **🗺️ 地図ビュー（フルスクリーンWeb GIS・MarkerCluster軽量化）**
   - 全画面地図による直感的な探索（デフォルト背景地図：国土地理院淡色地図）。
   - 全国の市区町村役場代表点（1,747件）および気象庁アメダス観測地点（1,286地点）をプロット。
   - Leaflet.markerclusterによるクラスタリング表示で、広域ズーム時も軽快に動作。
   - ピンのポップアップから気象庁公式天気予報、地理院地図、Google Maps、Wikipediaへ直結。
   - ※ α版ではノード（代表点）およびアメダス観測点のみ公開し、交通エッジライン（路線区間）は非公開としています。
3. **📖 階層ビュー（テーブル型一覧台帳 ＆ 多層ツリー・制度解説）**
   - 世界全251カ国・地域の一覧を、検索可能なテーブル形式（`data-table`）で表示。
   - 日本の地方（8地方）➔ 47都道府県 ➔ 1,747市区町村 / 171政令市行政区の多層ツリー構造。全地方一括展開/折りたたみ機能付き。
   - 自治体データ（種別・自治体名・かな・全国地方公共団体コード・代表座標・気象庁天気予報/外部URL/地図連携ボタン）を整然とした一覧テーブルで閲覧。
   - テーブル内の「地図」ボタンから該当ピンへ自動移動し、クラスタを展開してポップアップを開くフォーカス連携を装備。
   - 先行国（日本・オーストリア・台湾・韓国・スイス・イタリア）の公的行政階層・気象警報網・交通体系をまとめた公式制度解説ガイド（表示・非表示の折りたたみ可能）。
   - ※ α版では親子リレーション未完了の「郡」および「支庁・総合振興局・振興局」は非公開としています。

## 📁 ディレクトリ構成

- `web/public/`: 一般公開Webサイト（GitHub Pages配信ディレクトリ）
- `web/explorer/`: 机上探索・管理者用Web GISツール
- `data/master/`: 正本マスターデータ（CSV形式）
- `docs/`: プロジェクト仕様書・データベース設計書・制度調査レポート
- `scripts/`: データ調達・検証・静的ビルド用スクリプト群
- `tools/`: データ管理・整合性検査ツール
