# 世界交通網・地域データ基盤 (Global Transit & Territory Archive)

世界じゅうの過去から現在まで存在・計画された「交通網」と「国・地域・区域」のデータを収集・整理し、1つにまとめた統合データ基盤アーカイブです。

---

## 🌐 公開Webサイト

本プロジェクトの一般公開Webサイトは、GitHub Pagesを通じて以下のURLで公開されます。

🔗 **公開URL**: [https://sasamichi.github.io/PJT_Main/](https://sasamichi.github.io/PJT_Main/)

---

## 🗺️ 主な機能と収録コンテンツ（開設当初：国・地域・自治体先行公開）

1. **🏠 ホーム画面（プロジェクト案内・更新情報）**
   - プロジェクトの目的、先行公開データの案内、公式注記・免責事項。
2. **🗺️ 地図ビュー（フルスクリーンWeb GIS・ノード表示）**
   - 全画面地図による直感的な探索。
   - 全国の都道府県庁代表点および市区町村役場代表点ノードをプロット。
   - 独自ベクターSVGバッジアイコン体系（都府県庁・市区町村役場）による軽快な動作。
   - ※ 開設当初はノード（代表点）のみ公開し、交通エッジラインは非公開としています。
3. **📖 階層ビュー（仮サイト仕様のテーブル型 ＆ 多層ツリー・制度解説）**
   - 世界全251カ国・地域の一覧を、検索可能なテーブル形式（`data-table`）で表示。
   - 日本の地方（8地方）➔ 47都道府県 ➔ 政令市/市区町村の多層ツリー構造。
   - 自治体データ（種別・名称・コード・代表座標・詳細アクション）を整然とした一覧テーブルで閲覧。
   - 先行国（日本・オーストリア・台湾・韓国・スイス・イタリア）の公的行政階層・気象警報網・交通体系をまとめた公式制度解説ガイド。
4. **📋 詳細ナレッジパネル**
   - 自治体名や地図上の代表点をクリックすることで、公式天気予報（気象庁・tenki.jp・ウェザーニュース・Yahoo!天気）、代表座標、公式自治体サイト、Wikipediaリンクなどを備えた詳細カードを展開。

---

## 📁 ディレクトリ構成

- `web/public/`: 一般公開Webサイト（GitHub Pages配信ディレクトリ）
- `web/explorer/`: 机上探索・管理者用Web GISツール
- `data/master/`: 正本マスターデータ（CSV形式）
- `docs/`: プロジェクト仕様書・データベース設計書・制度調査レポート
- `scripts/`: データ調達・検証・静的ビルド用スクリプト群
- `tools/`: データ管理・整合性検査ツール
